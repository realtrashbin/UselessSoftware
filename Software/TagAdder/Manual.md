> [!NOTE]
> This file is intended for the **WINDOWS** Console and may not work on other Operating Systems.

> [!IMPORTANT]
> A "tag" within the scope of this program is a string added to the end of a file.

Usage is simple, you load into the Windows Command prompt by using `Win+R` then you
use the `cd` command to get into the directory where TagAdder is held on your computer
you then must run the name of the program `TagAdder` and then state two arguments both separated by space:
name of the file and the tag you wish to add. The program will then add the tag to the end of the file.
